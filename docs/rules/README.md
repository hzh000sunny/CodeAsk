# CodeAsk 跨版本规则

`docs/rules/` 用于存放**跨版本通用规则**。

这些规则不是某个单独版本的临时实现细节，而是会约束多个版本、多个模块和后续演进方向的稳定产品规则。

适合放在这里的内容：

- 文档规则
- 报告命名与写作规则
- 跨版本一致的交互约束
- 长期沿用的数据表达规则

不适合放在这里的内容：

- 某个版本独有的临时方案
- 单一版本的实施步骤
- 只在局部组件中生效的短期细节

- [问题定位报告规则](./problem-report.md)
- [UI 反馈规则](./ui-feedback.md)
- [升级兼容与数据目录规则](./upgrade-compatibility.md)
